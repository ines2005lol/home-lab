# Lab 02 – Network Discovery

## Objective

This lab focuses on discovering hosts and services within an isolated virtual network using basic networking tools and Nmap.

## Goals

* Configure and verify communication between virtual machines.
* Test connectivity using ICMP.
* Understand ARP and MAC addresses.
* Discover live hosts.
* Enumerate services running on a Windows machine.
* Document findings in a professional format.

## Files

* `setup.md` – Lab environment and network configuration
* `connectivity.md` – Ping testing
* `arp.md` – ARP analysis
* `nmap.md` – Network scanning
* `findings.md` – Observations and lessons learned
