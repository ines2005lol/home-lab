# Windows 10 Installation

## Objective

Set up a Windows 10 virtual machine to act as a target system for security testing.

## Environment / Tools Used

- Windows 10
- VirtualBox

## Steps

1. Created a Windows 10 virtual machine.
2. Configured CPU, RAM, and storage settings.
3. Installed Windows 10.
4. Completed the initial Windows setup.
5. Verified that the system runs correctly.

## Result

Windows 10 was successfully installed and will be used as the target machine in the lab.

## Lessons Learned

- Creating Windows virtual machines.
- Managing virtual hardware resources.
- Preparing a controlled environment for cybersecurity practice.
