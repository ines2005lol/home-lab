# VirtualBox Setup

## Objective

Install and configure VirtualBox as the virtualization platform for creating a cybersecurity home lab.

## Environment / Tools Used

- Host OS: Windows
- Hypervisor: Oracle VirtualBox

## Steps

1. Downloaded and installed VirtualBox.
2. Configured VirtualBox settings for running virtual machines.
3. Prepared the environment for Kali Linux and Windows 10 virtual machines.

## Result

VirtualBox was successfully installed and ready to host virtual machines.

## Lessons Learned

- Understanding the role of virtualization in cybersecurity labs.
- Creating and managing virtual machines.
- Basic VirtualBox configuration.
