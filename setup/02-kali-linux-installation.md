# Kali Linux Installation

## Objective

Install Kali Linux as the security testing machine for the home lab.

## Environment / Tools Used

- Kali Linux
- VirtualBox

## Steps

1. Created a new Kali Linux virtual machine.
2. Assigned system resources:
   - CPU: 6 cores
   - RAM: 8 GB
3. Installed Kali Linux.
4. Completed the initial configuration.
5. Verified that Kali Linux boots correctly.

## Result

Kali Linux was successfully installed and is ready to be used for cybersecurity exercises.

## Lessons Learned

- Installing a Linux operating system in a virtual environment.
- Configuring VM hardware resources.
- Understanding Kali Linux's role in penetration testing.
